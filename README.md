## Featured build: Voltair AI HR Suite

A fully automated hiring system — built first for our own hiring, now available to others.

- **Work queue, not a funnel** — every candidate resolves to one recommended action, ranked by urgency
- **AI shortlist** — semantic search plus per-candidate scoring, cited with evidence
- **Résumé chat** — ask the candidate pool a question in plain English, grounded strictly in résumés on file
- **Auto-filed résumé bank** — new uploads sorted to the right open role automatically
- **DPDP-compliant by design** — private storage, demonstrable consent, no fully automated decisions

Six distinct AI jobs run under the hood: résumé understanding, semantic recall (768-dim embeddings), fit scoring that penalises keyword-stuffing, durable batch screening, per-candidate interview questions, and automatic filing. Built on Next.js, Supabase with pgvector, and Google Gemini.
